
# CyberCipher2025_Adv_B045

## Overview
This repository contains the source code and resources for **CyberCipher2025_Adv_B045** submission, a web-based chatbot platform built using Python and HTML templates.

## Contents
- **server.py** — main server application  
- **chatbot.py** — chatbot logic  
- **log.txt** — runtime log file  
- **Templates/** — HTML templates for the user interface  
- **ModelTuning/** — directory reserved for model-training assets  
- **__pycache__/** — auto-generated Python bytecode cache  
- **README.md** — project documentation  

## Features
- Web interface served by the Python backend  
- Chatbot logic implemented in a standalone module  
- HTML templating for UI  
- Logging of system events and interactions  
- Structure prepared for model-tuning expansion  


## Setup & Usage

### 1. Clone the Repository
```bash
git clone https://github.com/BhaviRathore/CyberCipher2025_Adv_B045.git
````

### 2. Navigate Into the Project Directory

```bash
cd CyberCipher2025_Adv_B045
```



### 3. Run the Server

```bash
python server.py
```

### 4. Open the Application

Open your browser and go to the URL printed by the server, such as:

```
http://localhost:5000
```

### 5. Interact With the Chatbot

Use the web interface served from the `Templates/` directory.


## Project Architecture

* **Frontend:** HTML templates stored in `Templates/`
* **Backend:** Request handling and routing in `server.py`
* **Chatbot Engine:** Core chatbot logic in `chatbot.py`
* **Logging:** Activity and error logging in `log.txt`
